Features

Everything you need. Nothing you don't.

MyroClient strips PvP clients back down to what actually matters in a fight — then adds the parts every modern client is missing.

Lightweight by design

No background bloat, no telemetry, no fifty modules you'll never touch. MyroClient runs light so your FPS stays high when it counts — mid-fight, not in a menu.

Modern UI

A clean, redesigned interface that doesn't look like it's from 2016.

Built for PvP

Crosshair tweaks, hit indicators and combat-focused HUD elements — the stuff that actually wins fights.

Easy install & customization

Download, run, done. Every setting lives in one clean panel — reorder your HUD, tweak keybinds, swap modules without touching a config file.

Safe & open source

The full source is public. No hidden network calls, no obfuscated jars — inspect it yourself or trust the community that already has.

Compatibility

Built for the servers you're already on

MyroClient ships with presets tuned for the biggest modern PvP servers, so your HUD and modules are ready the moment you connect.

About the project

Made by a PvP player, for PvP players

MyroClient started as a frustration with existing clients — too heavy, too cluttered, too many features nobody in a real fight actually uses. We stripped it down and rebuilt it around one goal: get out of your way.

Every module is opt-in, every setting is one click away, and the entire codebase is open for anyone to read, fork, or audit. No hidden telemetry, no locked-behind-a-paywall features — just a fast, modern client built around how modern PvP servers actually play.
